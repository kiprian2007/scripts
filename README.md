# scripts

Полезные скрипты на каждый день.

## find_dupes.py — поиск дублей картинок

Находит одинаковые картинки (JPEG, PNG, WebP) в папке и раскладывает каждую группу
дублей в отдельную подпапку: `_dupes\001`, `_dupes\002`, ...

Сравнивает по содержимому, а не по байтам, поэтому находит дубли с разными именами,
разрешением, форматом и качеством сжатия. Ничего не удаляет и не перезаписывает —
файлы только перемещаются.

### Установка

Нужны Python 3.8+ и Pillow:

```
pip install pillow
```

### Запуск

В папке с картинками:

```
python find_dupes.py
```

| Ключ | Что делает |
| --- | --- |
| `D:\Photos` | обработать указанную папку вместо текущей |
| `-n` | только показать список дублей, ничего не перемещать |
| `-k` | картинку с самым большим разрешением оставить на месте, переместить только её копии |
| `-d Дубли` | другое имя папки для дублей вместо `_dupes` |
| `-r` | искать и в подпапках |
| `-t 6` / `-t 20` | порог различия: меньше — строже, больше — мягче (по умолчанию 12) |
| `-o dupes.txt` | дополнительно сохранить отчёт в файл |

Перед первым запуском на новой папке стоит прогнать с `-n` и посмотреть, что
скрипт считает дублями.

### Как себя ведёт

- По умолчанию перемещается вся группа целиком, включая «оригинал», чтобы копии
  лежали рядом и их было удобно сравнить.
- При повторном запуске уже разложенные файлы не трогает, новые группы получают
  следующие номера.
- Если в подпапке уже есть файл с таким именем, второй получает имя вида `имя (2).jpg`.

### Ограничения

Дублями считаются только копии одного и того же кадра. Обрезанные, повёрнутые или
отзеркаленные версии, а также картинки с добавленной рамкой или крупным водяным
знаком найдены не будут.
